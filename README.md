## Overview

**Appetizers** is a native iOS restaurant-ordering application. Users can browse a menu, open an appetizer to view its description and nutritional information, add items to an order, remove items with a swipe action, and update account preferences.

## Features

- Browse appetizers with images, names, and prices
- View item descriptions and nutritional information
- Add appetizers to an order
- Review the current order and total price
- Remove items using swipe-to-delete
- Edit personal information and dining preferences
- Navigate between Home, Account, and Order tabs

## Built With

## App Flow

1. Browse the appetizer menu.
2. Select an item to view more information.
3. Add the item to the order.
4. Review or remove items from the Order tab.
5. Place the order using the order summary button.
